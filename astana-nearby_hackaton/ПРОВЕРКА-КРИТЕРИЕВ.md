# Соответствие заданию Smart City

Проверка от 19.10.2026 по предоставленному заданию, исходному коду и автоматическим тестам. Это внутренняя оценка готовности, не оценка жюри. Живой прогон API в рамках этой проверки не выполнялся.

| Требование | Состояние и доказательство | Что остаётся |
|---|---|---|
| Концепция и аудитория | Городской помощник для жителей, туристов и небольших групп; описание в README | Для выступления кратко сформулировать пользу и отличие от обычной карты. |
| Интерактивный прототип | Локальное приложение Python + браузер, запрос, геопозиция, уточнения, карточки | Прогнать реальные ключи перед демонстрацией. |
| RAG: POI + генерация | Разбор Gemini → поиск/фильтры 2ГИС → генерация действия по записям; есть резервные шаблоны | При показе RAG нужен успешный ответ Gemini; шаблон сам по себе не демонстрирует генерацию. |
| Автоматизированный сбор | collect_2gis.py, SQLite с пространственным индексом; запросные выборки после поиска | Продемонстрировать реальный сбор и журнал; 265 — только старый снимок, не весь город. |
| Поля датасета | Название, координаты, описание, категории, расписание и доступные рейтинги; контакты опциональны | Полнота зависит от ответа и прав API. |
| Сценарии и ожидаемый ответ | Переписанный СЦЕНАРИИ.md, включая все пять примеров задания | Отдельно заполнить протокол живой проверки. |
| 1–3 конкретных варианта | Сейчас до пяти карточек по ранее выбранному поведению | Есть расхождение с ожидаемым форматом задания. Для строгого соответствия согласовать изменение выдачи до трёх. |
| Время, локация, контекст | Фильтры, уточнения, приближённый путь туда/обратно, ночное расписание | Нет маршрутизации по дорогам; сценарий перед вылетом покрыт только безопасным отказом. |
| Краткое «почему» и действие | Есть в карточке и «Подробнее»; источник и генерация различаются | Генерация и язык зависят от доступности Gemini. |
| Приватность и недостоверные сведения | Предупреждения, источники, скрытые ключи, без сохранения сырых запросов и личных координат в запросном датасете | Текст запроса получает Gemini, центр поиска получает 2ГИС; это нужно объяснять. |
| Репозиторий / архив | Есть публичная папка и архив; новый документ надо загрузить в GitHub | Проверять именно обновлённые файлы в репозитории. |
| Выступление 5–7 минут | В этом задании явно требуется | Готовность выступления не подтверждена; слайды не создавались по просьбе участницы. |
| Видео демо YouTube по ссылке | Требуется заданием | Наличие загруженного видео и рабочей ссылки не подтверждено. |

## Дополнительные цели

- Группы 3–5 человек: реализованы через естественный запрос; совпадения и компромиссы, без гарантии вместимости.
- Мультиязычность: RU / KK / EN; не произвольное определение любого языка.
- Мини-маршрут из трёх мест: не реализован. Карточки — альтернативы, не остановки маршрута.
- Локальные события: не реализованы. Театр или клуб в каталоге не равен актуальному событию.
- Подтверждённая доступность для ограниченной подвижности: не заявляется; отдельный пользовательский фильтр убран.

## Приоритет перед сдачей

1. Живой прогон прогулки, кофе и группы: Gemini подключён, филиалы реально соответствуют запросу; при пустой выдаче честно показать границу данных.
2. Показать автоматический сбор и пример его результата. Не включать ключи в запись экрана и GitHub.
3. Загрузить обновлённый СЦЕНАРИИ.md и проверить README: не обещать веб-проверку Gemini, события, полный каталог или готовые маршруты.
4. Подготовить выступление и YouTube-ссылку согласно требованиям организаторов. Задание просит PDF/слайды; отменить это требование может только организатор.
5. Решить вопрос числа карточек: в текущей версии сохраняются запрошенные ранее пять, хотя в примерах задания ожидаются 1–3.

## Что не стоит говорить жюри

«В базе все места Астаны», «Gemini проверил всё в интернете», «точно открыто», «розетки гарантированы», «готовый безопасный маршрут до вылета» — эти утверждения не подтверждаются текущей реализацией.

268 тестов успешно проверяют программную логику на тестовых данных. Это не 268 живых проверок заведений и не гарантия работоспособности внешних API на выступлении.
