# Астана рядом

ИИ-помощник для прогулок и досуга в Астане.

Пользователь описывает, где находится и чем хочет заняться. Приложение понимает пожелания, ищет ближайшие подходящие места через 2ГИС и показывает рекомендации с объяснением выбора.

## Возможности

- Поиск по геопозиции, выбранному району или месту из текста.
- Понимание запросов через Gemini.
- Рекомендации с учётом интересов, расстояния и доступного времени.
- Групповой подбор для 3–5 человек с разными пожеланиями.
- Интерфейс на русском, казахском и английском.
- Рейтинги, расписание и ссылки на карточки 2ГИС.
- Компактные карточки с раскрываемыми подробностями.

## Примеры запросов

> Я возле Mega Silk Way, хочу кофе рядом.

> Я с ребёнком, ищу парк или детскую площадку рядом.

> Нас четверо, мы возле Байтерека. Хотим посмотреть архитектуру и выпить кофе. Есть два часа, ищем рядом.

> Нас четверо: двое хотят кофе, двое — в музей. Что можно выбрать поблизости?

Если информации недостаточно, помощник задаёт уточняющий вопрос.

## Как это работает

1. Приложение определяет отправную точку.
2. Gemini разбирает пожелания пользователя.
3. Сервер запрашивает подходящие категории в 2ГИС с сортировкой по расстоянию.
4. Приложение проверяет ограничения и актуальность записей.
5. Пользователь получает до пяти отдельных вариантов.

Для группы показываются совпадения пожеланий и возможные компромиссы. Рекомендации не объединяются в готовый маршрут.

## Датасет и автоматизация сбора

Источник данных — официальный Places API 2ГИС.

Сохраняются название, координаты, категория, описание, расписание, доступные рейтинги, ссылка и время получения записи.

После пользовательского запроса полученные выборки сохраняются в `data/request-datasets/`.

Также реализован отдельный автоматизированный сборщик:

```bash
python3 -B collect_2gis.py
```

Он обходит категории и страницы API, удаляет дубликаты по ID, исключает закрытые и удалённые записи. Результаты сохраняются в JSON и SQLite с пространственным индексом.

Это ограниченная выборка, а не полный каталог Астаны. Объём зависит от выдачи и квоты API. Ключи и локальные файлы данных не включены в публичную сборку.

## Технологии

- Python 3.9+ и стандартная библиотека.
- HTML, CSS, JavaScript.
- SQLite.
- Gemini API.
- 2ГИС Places API.

Дополнительные Python-библиотеки не требуются.

## Запуск

Понадобятся Python 3.9+, интернет и собственные ключи Gemini и 2ГИС Places API.

Скачайте проект и откройте терминал в папке с `app.py`.

### macOS / Linux

```bash
python3 -B app.py
```

### Windows

```powershell
py -B app.py
```

Введите ключи по запросу в терминале. Символы при вводе скрыты. Ключи не записываются на диск.

Откройте в браузере:

http://127.0.0.1:8765/

Для остановки нажмите Ctrl+C.

## Поддержка устройств

Локальный запуск проверен на macOS. Запуск через Python предусмотрен для Windows и Linux, но на этих системах пока не проверен.

Интерфейс адаптирован для узких экранов. Для доступа с телефона или планшета нужен отдельно опубликованный сервер с HTTPS.

Загрузка проекта на GitHub не публикует работающий сайт. GitHub Pages не запускает Python-сервер.

## Ограничения

- Расстояние рассчитывается по прямой, время пешком приблизительное.
- Режим работы, свободные места, цены и наличие блюд нужно уточнять перед посещением.
- Вместимость для группы и бронирование не проверяются.
- Места с известным рейтингом ниже 3/5 исключаются; места без оценки допускаются.
- Доступность внешних API зависит от ключей и квот.
- При недоступности Gemini используется явно обозначенный локальный разбор.
- Координаты передаются в 2ГИС для поиска ближайших мест; автоматически в Gemini они не отправляются.
- Отсутствует связь с мероприятиями в городе.
