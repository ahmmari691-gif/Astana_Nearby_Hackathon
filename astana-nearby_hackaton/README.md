# Астана рядом

ИИ-помощник для прогулок и досуга в Астане. Хакатонный прототип на Python 3.9+,
без дополнительных библиотек. Интерфейс на русском, казахском и английском.

## На каких устройствах работает

| Устройство / система | Текущая поддержка |
| --- | --- |
| Mac, macOS | Локальный запуск; проверено на Mac разработки. |
| Компьютер с Windows | Предусмотрен запуск через Python; на Windows пока не протестировано. |
| Компьютер с Linux | Предусмотрен запуск через Python; на Linux пока не протестировано. |
| iPhone / iPad | Интерфейс адаптирован к узкому экрану. Для доступа с этих устройств нужен опубликованный сервер; готового мобильного приложения нет. |
| Android | Интерфейс адаптирован к узкому экрану. Для доступа нужен опубликованный сервер; установка APK не предусмотрена. |
| GitHub Pages | Только статическая часть. Полное приложение с Python и API здесь не работает. |

Сейчас это локальное приложение: Python-сервер и браузер работают на одном компьютере.
Внешние сервисы Gemini и 2ГИС требуют интернета. Публикация кода на GitHub сама по себе
не создаёт работающий сайт.

## Подготовка для компьютера

1. Установите **Python 3.9 или новее** с https://www.python.org/downloads/ либо через пакетный менеджер своей системы.
2. На GitHub нажмите **Code → Download ZIP**, затем распакуйте архив.
3. Откройте папку, в которой находится **app.py**. Не запускайте проект изнутри ZIP.
4. Откройте Terminal / PowerShell в этой папке. Если терминал открыт в другом месте,
   перейдите в папку командой `cd`, указав путь в кавычках.
5. Подготовьте собственные ключи Gemini и HTTP Places API 2ГИС.

Дополнительные Python-библиотеки, Node.js и `pip install` не нужны: сервер использует стандартную библиотеку Python.

### macOS

Откройте Terminal в папке проекта и выполните:

```bash
python3 --version
python3 -B app.py
```

Также можно дважды нажать **Запустить.command**. Если macOS блокирует запуск скачанного
файла, используйте команду выше в Terminal.

### Windows

Откройте папку проекта в Проводнике, нажмите правой кнопкой мыши в свободном месте
и выберите **Открыть в Терминале**. В PowerShell выполните:

```powershell
py --version
py -B app.py
```

Если команда `py` не найдена, но Python установлен, попробуйте:

```powershell
python --version
python -B app.py
```

Если обе команды не найдены, установите Python и включите добавление Python в PATH,
затем заново откройте терминал. Файлы **.command** предназначены для macOS и на Windows не запускаются.

### Linux

Установите Python 3 средствами своего дистрибутива, откройте терминал в папке проекта:

```bash
python3 --version
python3 -B app.py
```

Для автоматического открытия страницы нужен браузер и графическая среда.
Если страница не открылась автоматически, откройте её вручную по адресу ниже.
Файлы **.command** предназначены для macOS; на Linux используйте команду Python.

### После запуска — одинаково для всех компьютеров

1. На запрос **Gemini key** вставьте ключ Google AI Studio и нажмите Enter.
2. На запрос **2ГИС Places API key** вставьте ключ 2ГИС и нажмите Enter.
3. Символы при вводе не отображаются — это нормально. Каждый ключ проверяется перед подключением.
4. В браузере откроется http://127.0.0.1:8765/. Если нет — откройте этот адрес вручную.
5. Оставьте окно терминала открытым. Для остановки нажмите **Ctrl+C** / **Control+C**.

Ключи хранятся только в памяти. После остановки введите их снова.
Enter без ключа пропускает сервис: без Gemini нет разбора пожелания через ИИ,
без 2ГИС нет проверенных рекомендаций.

Если порт **8765** занят, остановите предыдущий запуск через Ctrl+C в его терминале.
После изменения Python-кода требуется остановить и запустить приложение заново,
а затем обновить страницу браузера. Обновление страницы само по себе не обновляет Python-сервер.

## Телефоны, планшеты и доступ по ссылке

В этой версии адрес **127.0.0.1** работает только на том компьютере, где запущен Python.
На телефоне тот же адрес означает сам телефон, поэтому ссылка с компьютера на нём не откроется.

Для доступа с iPhone, Android или другого компьютера требуется отдельное развёртывание:
Python-сервер на хостинге, домен с HTTPS, настройка сетевого адреса и разрешённых Host/Origin
в app.py, серверное хранение ключей и ограничение доступа и расходов API.
Текущий код намеренно слушает только localhost и не является готовой конфигурацией публичного сервера.
Просто заменить IP в браузере или загрузить файлы на GitHub Pages недостаточно.

В опубликованной версии пользователь сможет открывать адаптивный интерфейс в браузере телефона.
Для определения геопозиции нужен HTTPS и разрешение пользователя; при отказе можно указать место текстом.
Сейчас такое развёртывание не входит в архив и на мобильных устройствах не проверялось.

Получить ключи: https://aistudio.google.com/apikey и https://platform.2gis.ru/.
Бесплатный доступ Gemini и демо-доступ 2ГИС имеют квоты; их доступность зависит от проекта.
Приложение выбирает поддерживаемую текстовую Flash/Flash-Lite из списка моделей
и проверяет её запросом. GEMINI_MODEL позволяет задать предпочтительную поддерживаемую модель.
Ключи также можно передать через GEMINI_API_KEY и DIGIS_API_KEY.
Не добавляйте ключи в код или репозиторий.

## Как пользоваться

Выберите район, разрешите геопозицию или напишите «Я у Экспо, хочу в музей» без выбора района.
При нескольких совпадениях стартовой точки приложение предлагает выбор.
Gemini разбирает пожелание, затем 2ГИС возвращает места подходящих категорий.
Если предпочтения неясны, приложение задаёт уточняющий вопрос и ждёт ответа.
Карточки содержат расстояние, примерное время, причину выбора, план и ссылку на филиал.
Без Gemini доступен явно обозначенный локальный разбор, без 2ГИС нет проверенных рекомендаций.

## Категории

Кафе, рестораны, парки, сады, площадки для детей, музеи, галереи, библиотеки,
культурные центры, достопримечательности, смотровые площадки, кинотеатры,
ночные клубы, караоке, боулинг, театры, концертные площадки, бары, пабы,
квесты, VR, игровые клубы, батутные и детские центры, аттракционы, бассейны,
аквапарки, катки, спортплощадки, СПА, бани/сауны, торговые центры, магазины,
экскурсионные службы. Названия и категории получаются из 2ГИС.

## Автоматизированный сбор данных

Старая база OpenStreetMap не используется. Массовый сбор при запуске отключён.
Выборки после пользовательских запросов сохраняются в data/request-datasets/:
название, координаты, категория, описание, расписание, доступные рейтинги,
ссылка и время получения. Хранятся до 100 последних вариантов фильтров.
Полный текст запроса и ключи в эти файлы не записываются.

Для воспроизводимого сбора по категориям:

```bash
python3 -B collect_2gis.py
```

Сборщик спрашивает ключ 2ГИС. Категории обходятся по очереди, до 50 страниц
по 10 записей, общий бюджет — 600 запросов. Пустые и повторные страницы останавливают
обход. Дубли удаляются по ID филиала, закрытые и удалённые записи исключаются.
Это ограниченная выборка, не полный каталог города. Количество зависит от выдачи и квоты.
Пределы можно задать явно: `python3 -B collect_2gis.py --pages 100 --max-requests 1000`.
Контакты требуют отдельного разрешения ключа: `--contacts`.

Результаты: data/2gis-collected.json, data/2gis-raw.json, data/catalog-info.json,
data/catalog.sqlite. Журнал содержит категории, страницы, количество, время и причины остановки.
SQLite использует пространственный индекс; страница получает только ограниченную выборку рядом.
Файлы данных исключены из публичного архива и Git. Соберите их своим ключом перед демонстрацией.
Статистика последнего локального снимка — в DATASET_REPORT.md; исходные данные не входят в отчёт.

## Проверка и ограничения

```bash
python3 -B -m unittest discover -p 'test*.py'
```

Тесты проверяют логику на подготовленных ответах, не гарантируют доступность внешних API.
Требования к конкретной еде подтверждаются атрибутами источника; название и общая кухня
не доказывают наличие блюда. Текущее меню может меняться.
Запись в справочнике и расписание не гарантируют вход прямо сейчас. Кеш проверки — до двух минут.
Для ночного посещения требуется расписание на прибытие и всё посещение, время Астаны UTC+5.
Сеансы кино, концерты, билеты, отправление экскурсии и свободные дорожки не подтверждаются.
Карточка экскурсии относится к организатору. Розетки, тишина, возрастные ограничения и цены
без подтверждения не обещаются. Частные крыши и закрытые территории не предлагаются.
Перед вылетом приложение просит уточнить реальный запас времени, а не предлагает случайную прогулку.
Расстояние по прямой; время пешком — оценка, без построения дорожного маршрута.
Координаты выбранной точки передаются 2ГИС для поиска ближайших мест с `sort=distance`. Название стартового места также передаётся 2ГИС для поиска,
текст пожелания — Gemini для разбора. На бесплатном тарифе Google действуют свои условия обработки данных.

## Прогулка по городу

Добавлены набережные, бульвары, площади, пешеходные улицы и архитектурные места.
Если пользователь пишет только «хочу прогулку», приложение спрашивает стиль:
зелень и тишина, городская архитектура или оживлённые улицы.
Ответ учитывается вместе с первоначальным запросом, временем и локацией.
Прогулка с кофе может включать кафе и городские места как отдельные варианты.
Выдача сортируется по расстоянию: первыми идут ближайшие подходящие места.
Объекты 2ГИС, отличные от филиала организации, используют ссылку /geo/.
Приложение не строит реальный маршрут по дорожной сети и не подтверждает тишину или свободный вход.

## Необязательные поля времени и радиуса

По умолчанию время и радиус в форме не выбраны. Их можно указать в запросе:
«Я у Экспо, хочу в музей на 1 час, в пределах 2 км».
Можно совместить время из формы и радиус из текста или наоборот.
Если радиус не указан ни в форме, ни в тексте, приложение уточняет его. Время не обязательно: отсутствие времени означает отсутствие ограничения длительности. Ответ учитывается вместе с исходным пожеланием.
«Ближе», «рядом» и «недалеко» без явного расстояния означают до 1 км. Отдельного переключателя нет. Выбор сценария не подставляет время автоматически.
При разных явных ограничениях формы и текста применяется меньший предел. Фраза о неограниченном времени отменяет выбранный предел времени.

## Оформление

Палитра и иллюстрация главного экрана взяты из предоставленного SVG web/astana2.svg: синий, голубой, жёлтый и светлый фон. Иллюстрация адаптируется к узким экранам.

Уточнение отправной точки показывается карточкой с вопросом, полем ответа и кнопкой. Исходное пожелание сохраняется.

Время по умолчанию не ограничено; приложение не спрашивает, сколько времени есть. Если время указано явно, оно учитывается. Ограничение в четыре часа снято. Ближайшие подходящие места показываются первыми.

## Сначала отправная точка

Если район/геопозиция не выбраны, Gemini сначала выделяет текущее место, понимая русские написания и склонения («керуена», «меге»). Затем 2ГИС подтверждает объект и координаты. Только после этого разбираются пожелания и запрашиваются места. При неоднозначности предлагается выбор. Если точка уже выбрана, повторное распознавание не нужно. При сбое ИИ используется явный текстовый разбор; координаты никогда не придумывает модель.

Ответ «у меня много времени и мне не важно где» снимает ограничения времени и радиуса. Также понимаются «времени много», «никуда не спешу», «где угодно», «расстояние неважно». Поиск остаётся в пределах Астаны, ближайшие подходящие места идут первыми. Текущая отправная точка по-прежнему нужна для расчёта расстояния.

## Организации внутри ТЦ

После разбора пожелания приложение ищет публичные карточки ТЦ Астаны (до трёх страниц по 10 объектов), затем локально выбирает до двух центров в пределах 1 км от отправной точки. Отбор ТЦ выполняется локально; основной поиск ближайших мест передаёт центр поиска в 2ГИС. Для подходящих indoor-категорий выполняется поиск `search_type=indoor` с подтверждённым `building_id`, до трёх страниц на категорию в здании. Результаты объединяются с обычным поиском по ID филиала. В карточке показаны ТЦ и комментарий об этаже, если получены от источника. Если поиск ТЦ недоступен, сохраняется обычный поиск. Это ограниченный обход, не гарантия полного списка арендаторов; фильтры еды, времени и расстояния продолжают действовать.

Ответ разбора Gemini проходит строгую проверку. Безопасные различия представления (числа строками, true/false строками, null в необязательных полях) нормализуются. При ошибке формата выполняется не больше одного повторного запроса с инструкцией исправить JSON; ошибки доступа и квоты не повторяются. Неизвестные категории и некорректные требования к еде не игнорируются. При повторном сбое явно показывается локальный режим.

## Нижняя часть карточки

После плана показываются расписание только на дату запроса по времени Астаны, предупреждение о неподтверждённом открытии, адрес, ссылки, примечание о записи 2ГИС, рейтинги/отзывы и раскрываемый блок использованных данных. Расписание недельное и ориентировочное; оно не подтверждает фактическое открытие или праздничные исключения. При отсутствии нужного дня другие дни не подставляются.

Поиск 2ГИС сначала сортирует места по близости к точке из геопозиции, выбранного района или распознанного адреса. В запрос передаются `point`, `sort=distance` и радиус пользователя (до предела API 50 км). Для режима по всей Астане применяется 50 км на стороне API; итоговые ограничения проверяются локально. Проверяются до трёх страниц каждой категории. Кэш зависит от точки и радиуса. Координаты не включаются в запрос к Gemini и не записываются в датасет запросов.

Рекомендации исключают места с известным рейтингом филиала 2ГИС ниже 3/5. Ровно 3/5 и выше допускаются. Отсутствие оценки не исключает место; неверные оценки и рейтинг всей организации не подменяют оценку филиала. Фильтр повторяется после обновления карточки из API.

## Групповые рекомендации из текста (3–5 человек)

Отдельных переключателей, выбора количества и анкет участников нет. Напишите всё в основном запросе:

> Нас четверо, мы возле Байтерека. Хотим погулять, посмотреть архитектуру и выпить кофе. Есть два часа, ищем рядом.

Или укажите разные пожелания:

> Нас четверо, мы возле Байтерека. Двое хотят кофе, двое — в музей. Ищем рядом, есть два часа.

Количество участников распознаётся из текста («нас четверо», «нас 3», «мы впятером»). Gemini за один запрос выделяет общие условия и распределяет только явно указанные пожелания; выдумывать личные интересы нельзя. При недоступном ИИ используется обозначенный локальный разбор, который может не разделить сложные пожелания по участникам. Если расстояние или исходная точка не указаны, приложение задаст уточняющий вопрос.

Сначала показываются варианты с большим числом подтверждённых совпадений по индивидуальным пожеланиям, затем ближайшие. Для общего запроса без распределения интересов поиск идёт по общим пожеланиям. Три места не объединяются в маршрут. Явные исключения, конкретная еда, ограничения времени и радиуса сохраняются. Неподтверждённые розетки, тишина и условия для детей не считаются доказанным совпадением. Вместимость, общий столик и свободные места нужно уточнять у заведения.

Копия до добавления группового подбора: `astana-nearby-before-groups.zip`.

Групповой ответ Gemini нормализуется: для общего пожелания достаточно одного `shared_profile`, без повторения профиля для каждого человека. При распределённых интересах проверяются число участников и извлечённые пожелания; различия регистра, пробелов и пунктуации допускаются. При ошибке JSON/схемы выполняется одна попытка исправления ответа, а ошибки квоты и доступа не повторяются.

## Компактный интерфейс

На основной форме видны геопозиция, запрос и кнопка поиска. Район, время, радиус, сценарий и условия находятся в свёрнутом блоке «Настроить поиск». Выбранные значения продолжают действовать после сворачивания; рядом с заголовком показано число выбранных параметров.

Карточки показывают название, категорию, расстояние, пешее время, причину выбора, рейтинг (либо отсутствие оценки), адрес при наличии и ссылки на 2ГИС/карту. Короткое предупреждение перед посещением остаётся видимым. В «Подробнее» находятся план, время на месте и с возвращением, расписание на выбранный день, детали группового подбора, отзывы и «Какие данные использованы». Поиск и проверки источников не изменены.

Копии до изменения: `astana-nearby-before-compact.zip` (весь проект с локальными данными) и `astana-nearby-before-compact-ui.zip` (прежняя папка web). Для возврата только оформления восстановите папку web из второй копии и обновите страницу; для возврата всего проекта остановите сервер и распакуйте полную копию в отдельную папку.
