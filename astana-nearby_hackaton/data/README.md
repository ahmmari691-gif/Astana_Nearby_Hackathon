# Данные

Готовая база 2ГИС не распространяется в публичной версии репозитория.
Приложение получает данные через официальный Places API после пользовательского запроса
и сохраняет выборки в request-datasets/. Они исключены из Git через .gitignore.

Для отдельного массового сбора запустите `python3 -B collect_2gis.py` из корня проекта.
Введите свой ключ в Terminal. После успешного сбора появятся JSON, журнал и SQLite.
Ключ не записывается в эти файлы. Доступность полей зависит от разрешений ключа.
Использование и распространение данных определяется условиями доступа 2ГИС.
